# Technology Stack

## 1. Frontend

### HTML5

Used to create the structure of application pages and forms.

### CSS3

Used for styling, layouts, spacing, and responsive customization.

### JavaScript

Used for client-side logic, API calls, DOM manipulation, form handling, and dynamic content.

### Bootstrap 5

Used for responsive layouts and reusable UI components.

### Fetch API

Used to communicate with backend REST endpoints.

## 2. Backend

### Java

Used as the primary backend programming language.

### Spring Boot

Used to create and configure the backend application.

### Spring Web

Used for REST controllers and HTTP API endpoints.

### Spring Data JPA

Used for repository and database access.

### Hibernate

Used as the ORM implementation for JPA.

### Bean Validation

Used to validate incoming data.

### Maven

Used for dependency management and project builds.

## 3. Database

### MySQL

Used as the relational database for storing application data.

## 4. Development and Testing

- Git
- GitHub
- Postman
- MySQL Workbench
- IntelliJ IDEA / Eclipse / VS Code

## 5. Technology Flow

```text
HTML/CSS/JavaScript/Bootstrap
            |
         Fetch API
            |
        REST APIs
            |
       Spring Boot
            |
      Spring Data JPA
            |
          MySQL
```
