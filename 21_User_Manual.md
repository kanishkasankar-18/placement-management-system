# User Manual

## 1. Introduction

This manual explains how users can operate the Placement Management System.

## 2. Admin Workflow

### Step 1: Access Application

Open the frontend in a supported browser.

### Step 2: Open Dashboard

The dashboard provides an overview of placement activities.

### Step 3: Manage Students

Open the Students section.

Admin can:

- Add a student
- View student details
- Edit student
- Delete student
- Search students

### Step 4: Manage Companies

Open Companies.

Admin can add and maintain company information.

### Step 5: Create Placement Drive

Open Placement Drives and enter:

- Company
- Job role
- Drive date
- Deadline
- Eligibility
- Required skills
- Location
- Package

### Step 6: Manage Applications

Open Applications to monitor submitted applications and update their status.

### Step 7: Record Results

Open Placement Results and record selected student details.

## 3. Student Workflow

### Step 1: Open Student Dashboard

View student-specific placement information.

### Step 2: Browse Drives

Review available placement drives and eligibility requirements.

### Step 3: Apply

Submit an application for an eligible placement drive.

### Step 4: Track Status

Check whether the application is:

```text
APPLIED
SHORTLISTED
INTERVIEW
SELECTED
REJECTED
```

### Step 5: View Result

View final placement information when available.

## 4. Good Practices

- Enter accurate information.
- Do not submit duplicate applications unless supported by the business rules.
- Verify data before deleting records.
- Keep login credentials private when authentication is enabled.
