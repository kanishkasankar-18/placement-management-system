# Limitations

## 1. Initial Version

The initial version is primarily designed as an academic mini-project and may not include all features required for a production enterprise system.

## 2. Authentication

If authentication is not implemented in the final version, role access is not production-secure.

## 3. Local Database

The default setup depends on a locally configured MySQL database.

## 4. Notification Services

Email and SMS notifications may not be included.

## 5. External Integrations

The system does not necessarily integrate with external job portals or company recruitment platforms.

## 6. Scalability

The initial implementation is intended for academic demonstration and may require additional infrastructure and optimization for large-scale deployment.

## 7. Security Hardening

A production deployment would require additional security controls such as:

- HTTPS
- Secure password storage
- Token/session management
- Access control
- Rate limiting
- Security headers
- Secret management
- Database access restrictions

## 8. Data Quality

The accuracy of reports depends on the correctness of information entered into the system.

## 9. Future Work

The limitations above can be addressed through the enhancements described in `23_Future_Enhancements.md`.
