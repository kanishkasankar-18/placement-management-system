# Problem Statement

## 1. Background

College placement activities involve large amounts of student, company, application, and placement data. When these activities are handled using spreadsheets, paper records, or disconnected systems, maintaining accurate and up-to-date information becomes difficult.

## 2. Existing Problems

Common problems include:

- Manual maintenance of student records
- Duplicate or inconsistent data
- Difficulty tracking placement applications
- Time-consuming company and drive management
- Difficulty generating placement statistics
- Limited visibility of application status
- Increased dependency on paperwork
- Difficulty maintaining historical placement information

## 3. Proposed Solution

The proposed Placement Management System provides a centralized web application where authorized users can manage placement information through a structured interface.

The system uses:

- HTML5, CSS3, JavaScript, and Bootstrap for the frontend
- Java and Spring Boot for backend services
- Spring Data JPA for persistence
- MySQL for data storage
- REST APIs for frontend-backend communication

## 4. Problem-to-Solution Mapping

| Problem | Proposed Solution |
|---|---|
| Manual records | Centralized database |
| Difficult updates | CRUD operations |
| Application tracking | Application module |
| Company management | Company module |
| Drive management | Placement Drive module |
| Result tracking | Placement Result module |
| Data inconsistency | Validation and database constraints |
| Limited statistics | Dashboard |
