# Project Scope

## 1. In Scope

The project includes:

- Student management
- Company management
- Placement drive management
- Application management
- Placement result management
- CRUD operations
- Search and filtering
- Dashboard statistics
- Input validation
- Exception handling
- MySQL persistence
- REST API integration
- Responsive frontend

## 2. User Scope

### Admin / Placement Officer

The admin manages placement-related master data and monitors applications and results.

### Student

Students can view placement opportunities, apply to drives, and track application and result information.

## 3. Technical Scope

The system is intended to run as a web application with:

- Browser-based frontend
- Spring Boot backend
- MySQL database
- REST API communication

## 4. Out of Scope for Initial Version

The following may be considered future enhancements:

- Production-grade cloud deployment
- SMS notifications
- Advanced AI-based placement prediction
- Mobile application
- Complex enterprise authentication
- Automated external job-board integration
